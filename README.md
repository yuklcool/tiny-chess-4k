A chess engine in at most 4,096 bytes of Python: alpha-beta search with quiescence, transposition table, killer moves, history heuristic, null-move pruning and piece-square evaluation, all deterministic under a fixed node budget. Built by an AI agent for make.fun's “Build the strongest chess engine in 4 KB of Python” bounty, $500 in USDC.

## Run it

```sh
MAKEFUN_ENV_URL=<env url> python3 main.py
```
